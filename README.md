# english-tutor-agent

Голосовой и текстовый репетитор по английскому для восьмиклассника — грамматика, тексты,
словарный запас и устная разговорная практика в одном инструменте с общей памятью о ученике,
не разные программы. Открывается в браузере, работает у него на компьютере.

Весь характер и правила — в `AGENTS.md`, в самом начале — «Кто ты и чего ты хочешь». Читает и
пишет это правила сам сервер (`index.js`) при каждом сообщении — ученику этот файл не показывают.

## Как это устроено для ученика

Открывает `http://localhost:3000` в браузере — обычная страница, не отдельная программа. Есть
кнопка микрофона (браузер сам слушает и озвучивает ответ, бесплатно, без установки чего-либо
дополнительного) и обычное поле ввода текста — можно и говорить, и печатать. Один и тот же
собеседник: пришлёт фото/текст упражнения — разбирает пошагово, как математика и физика;
заговорит просто так — практика устной речи, с мягкими поправками на ходу, не как экзамен.

## Как это устроено технически (для того, кто чинит/обновляет)

- **Голос** — Web Speech API самого браузера (Chrome), не отдельный сервис. Готовый рабочий
  код взят из открытого проекта `Abhijayshah/English-Tutor-AI` (MIT, см. `LICENSE.md`).
- **Мозг** — не оригинальные "личности"-заглушки того проекта, а свой `AGENTS.md` + реальная
  память об этом конкретном ученике из папки `memory/`, собираются в системный промпт заново
  на каждое сообщение (`buildSystemPrompt()` в `index.js`).
- **Память сохраняет сервер, не модель.** У модели нет прямого доступа к файлам (это не Cherry
  Studio с MCP) — вместо этого она обязана вывести один структурированный блок
  ```` ```memory_update ... ``` ```` в конце значимого фрагмента занятия; сервер вырезает его
  из ответа ученику и сам пишет в `memory/*.md` по фиксированному формату
  (`extractMemoryUpdate`/`applyMemoryUpdate` в `index.js`). Это надёжнее, чем у математики и
  физики: там модель сама решает, вызывать ли инструмент записи, и иногда просто пишет
  «сохранил», не сохранив ничего по-настоящему — здесь сервер не спрашивает разрешения.
- **Диалог с историей.** Оригинальный репозиторий отправлял каждое сообщение изолированно, без
  контекста предыдущих реплик — для пошагового разбора это не годится, добавлено хранение
  истории на сессию (`client.history` в `index.js`).
- **Уведомления в Телеграм** — сервер сам шлёт «начал»/«закончил» с длительностью при первом
  сообщении сессии и при отключении браузера — тот же бот, что уже используется у математики и
  физики (`TELEGRAM_BOT_TOKEN`/`TELEGRAM_CHAT_ID` в `.env`), но здесь это делает сам код
  напрямую, не отдельный скрипт-наблюдатель.

## Установка и запуск

1. Установить [Node.js](https://nodejs.org/) (LTS-версия).
2. Открыть терминал в этой папке, выполнить `npm install`.
3. Скопировать `env.example` в `.env`, вписать туда:
   - `OPENAI_API_KEY` — ключ [OpenRouter](https://openrouter.ai/) (платно по факту использования).
   - `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` — те же, что у math-tutor-agent/physics-tutor-agent.
4. Выполнить `npm start`.
5. Открыть `http://localhost:3000` в браузере (Chrome — самая надёжная поддержка голоса).

Без реального ключа OpenRouter приложение работает в демо-режиме — отвечает заготовленными
фразами, без настоящей проверки грамматики и без сохранения памяти (блок `memory_update`
формирует только настоящая модель).

## ⚠️ Перед первым использованием

`knowledge/curriculum.md` — программа по памяти, не сверена с реальным учебником ученика.
Владелец загрузит учебник — распознать и заменить программу реальным содержанием, тем же
способом, что уже сделано для физики.

## Структура

```
english-tutor-agent/
├── AGENTS.md              характер, правила, формат memory_update — сердце агента
├── index.js               сервер: голос/текст, сборка промпта, запись памяти, Телеграм
├── views/, public/         интерфейс в браузере (не переписан, только промпт/память новые)
├── knowledge/
│   └── curriculum.md       программа по темам (плейсхолдер, см. предупреждение выше)
├── memory/
│   ├── student_profile.md  профиль ученика, план следующего занятия
│   ├── competency_map.md   статус по темам
│   ├── session_state.md    состояние текущего занятия
│   └── lesson_history.md   журнал занятий
└── LICENSE.md              MIT, унаследована от исходного открытого проекта
```
